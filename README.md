## 🚀 Features

### ⏱️ Core Timer
- **Flap-style countdown clock** with smooth animations
- **Customizable duration** (1-240 minutes)
- **Pomodoro mode** - auto 5-min breaks (15-min every 4 sessions)

### 🎮 Gamification
- **8 Achievements** to unlock
- **Session tracking** (persisted in localStorage)
- **Day streaks** for consistent focus
- **Stats dashboard** showing total sessions & minutes

### 🚀 Rocket Animations
- **Progressive launch prep** - rocket rises & flames grow as timer progresses
- **Launch sequence** when focus session completes
- **Descent animation** - rocket returns during breaks
- **Explosion effects** for aborts, resets, and break endings

### 🔔 Notifications & Audio
- **Tick sounds** for final 30 seconds
- **Launch & explosion sound effects**
- **Browser notifications** at 30 seconds remaining
- **Completion alerts**

### 💥 Accountability Features
- **Abort button** - manual mission abort with explosion
- **5-minute pause timeout** - auto-abort if paused too long
- **Focus broken explosion** - rocket explodes if you reset mid-session

### 🤖 AI Learning Assistant Chatbot
- **Integrated Claude AI chatbot** - learn about AI systems while you focus
- **Multiple AI system demonstrations** - RAG, Lexicon, Symbolic, Generative, Composite
- **Educational responses** - explains which AI approach is used and why
- **Knowledge base** - built-in context for AI/ML topics
- **System tags** - visual indicators showing which AI systems are active
- **API key storage** - securely saved in localStorage

## 🚀 Quick Start

### Option 1: Direct File
Just open `index.html` in your browser!

### Option 2: Local Server
```bash
# Navigate to the project folder
cd focus-timer

# Start a local server
python -m http.server 8000

# Open in browser
# http://localhost:8000
```

---

## 🚀 How It Works

1. **Set your focus duration** (default: 25 minutes)
2. **Click Start** - rocket begins preparing for launch
3. **Focus on your work** - watch the rocket rise and flames grow
4. **Timer ends** - rocket launches! 🚀
5. **Break time** - rocket descends back to pad
6. **Break ends** - rocket explodes 💥 signaling work time
7. **Repeat** and unlock achievements!

## 🚀 Controls

| Button | Action |
|--------|--------|
| ▶ Start | Begin timer |
| ⏸ Pause | Pause (5-min limit before auto-abort) |
| ↺ Reset | Reset timer (explodes if running) |
